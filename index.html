Project 01 Positive-Unlabeled Learning

PU-
BOOST

PU-Boost treats potentially undiagnosed hypertension as a positive-unlabeled learning problem. A two-stage stratification procedure reconstructs a cleaner, balanced training set from diagnosed cases and heterogeneous unlabeled participants, improving test accuracy while substantially increasing sensitivity to missed positive cases.

67.23% Test accuracy
81.72% Sensitivity
729 False negatives
vs. logistic regression · +1.14 pp accuracy · +13.40 pp sensitivity · 534 fewer false negatives
